# Scientific Defense Dossiers

This directory is reserved for the notebook-specific and integrated scientific-defense documentation associated with the Polymer Informatics Atlas.

The defense materials are designed for manuscript discussion, PI interviews, viva-style questioning, and reproducibility review. They explain not only what each notebook did, but why the methodological choices are scientifically defensible, what conclusions are supported, what claims are not supported, and how each stage connects to the overall project.

The final public defense documents will be added after the v1.0 software/research release is archived. Until then, the six executed notebooks and the repository's release-facing tables provide the authoritative public scientific record.
