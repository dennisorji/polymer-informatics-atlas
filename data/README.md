# Data

The raw NeurIPS Open Polymer Prediction 2025 / Kaggle dataset is not redistributed here.

The project was developed from a core training table containing 7,973 unique, RDKit-valid polymer repeat-unit records with sparse measurements for Tg, FFV, Tc, Density, and Rg.

To reproduce the workflow, obtain the original dataset from its official source and follow the notebooks in order. Generated intermediate arrays, model weights, and notebook ZIP exports are intentionally excluded from version control because they are reproducible artifacts and can be large.
