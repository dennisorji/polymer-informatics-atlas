# Notebooks

The research workflow is organized into six executed notebooks that should be read and, when reproducing the analysis, run in order:

1. [`01_data_audit_and_atlas_foundation.ipynb`](01_data_audit_and_atlas_foundation.ipynb) — chemical integrity, target availability, interpretable descriptors, and curated atlas foundation.
2. [`02_polymer_representations_and_feature_engineering.ipynb`](02_polymer_representations_and_feature_engineering.ipynb) — polymer-specific representation auditing, wildcard-retention tests, count-Morgan design, and frozen feature spaces.
3. [`03_property_specific_baseline_modelling.ipynb`](03_property_specific_baseline_modelling.ipynb) — leakage-controlled random-split modelling, targeted tuning, untouched holdout evaluation, and residual diagnostics.
4. [`04_chemistry_aware_generalization.ipynb`](04_chemistry_aware_generalization.ipynb) — nearest-neighbour support analysis, chemistry-separated stress tests, and domain-shift interpretation.
5. [`05_shared_learning_and_reliability.ipynb`](05_shared_learning_and_reliability.ipynb) — masked multitask learning, complete-case ablation, neural ensembles, conformal calibration, and reliability signals.
6. [`06_interpretation_and_final_polymer_atlas.ipynb`](06_interpretation_and_final_polymer_atlas.ipynb) — frozen-model reconstruction, feature interpretation, Morgan-environment decoding, integrated chemical-space Atlas, property archetypes, and illustrative Pareto analysis.

Each notebook freezes and exports artifacts needed by subsequent stages. Model or representation choices are not revised after final holdout evaluation, and chemistry-aware validation is kept separate from conventional random-split interpolation.

Large intermediate arrays and model objects generated by the notebooks are intentionally excluded from version control. See [`../REPRODUCIBILITY.md`](../REPRODUCIBILITY.md) for the artifact and rerun policy.
