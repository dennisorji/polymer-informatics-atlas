# Polymer Informatics Atlas v1.0.0

First public release of the Polymer Informatics Atlas, a six-notebook polymer-informatics workflow covering data auditing, molecular representations, property prediction, chemistry-aware generalization, multitask learning, uncertainty quantification, Morgan-feature interpretation, and the final integrated polymer atlas.

Highlights:
- 7,973 polymer repeat units analyzed
- Five target properties: Tg, FFV, Tc, Density, and Rg
- Property-specific modelling with frozen holdouts
- Chemistry-separated generalization analysis
- Masked multitask learning and conformal prediction
- Interpretable Morgan-environment analysis
- Final Polymer Atlas and multi-property design analysis

The repository includes all six notebooks, curated result tables, summary figures, reproducibility documentation, and citation metadata.

Raw competition data and large intermediate artifacts are not redistributed.
