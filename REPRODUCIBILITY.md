# Reproducibility

## Execution model

The project is organized as six sequential notebooks. Each stage freezes and exports the artifacts needed by the next stage rather than silently recomputing or reselecting models after holdout evaluation.

The notebooks were developed in Google Colab and can be rerun there. Large generated arrays, fitted model objects, neural-network weights, and notebook ZIP exports are intentionally excluded from Git history.

## Data

Obtain the official NeurIPS Open Polymer Prediction 2025 training data from Kaggle. The core analysis uses `train.csv` and preserves the original sparse target-availability pattern.

Expected core population:

- 7,973 polymers;
- Tg: 511 observed labels;
- FFV: 7,030;
- Tc: 737;
- Density: 613;
- Rg: 614.

## Notebook order

Run the files in `notebooks/` from `01_...` through `06_...`.

Notebook 01 creates the curated master table. Notebook 02 freezes the interpretable, Morgan-count, and Hybrid representations. Notebook 03 freezes target-specific train/test partitions and property-specific predictive models. Notebook 04 evaluates chemical-domain support and chemistry-separated generalization. Notebook 05 evaluates shared learning and calibrated reliability. Notebook 06 reconstructs the frozen models for interpretation and builds the final Atlas.

## Leakage controls

- Train/test partitions are generated once and then frozen.
- Model selection and targeted tuning are performed only within the training side of the frozen Notebook 03 split.
- The final random holdout is not used to select a model family or representation.
- Scaling is performed inside the appropriate modelling pipeline when predictive.
- Chemistry-separated evaluation is reported separately from random-split interpolation.
- Reliability calibration uses a dedicated calibration subset separate from the reliability test set.
- Morgan-feature candidate screening uses training data before holdout permutation validation.

## Representation integrity

The primary local representation is a count Morgan fingerprint with radius 4, 2,048 hashed dimensions, chirality enabled, and polymer wildcard connection points retained.

Notebook 06 verifies exact regeneration of the archived Morgan representation before chemical decoding. A 100-polymer fingerprint audit produced zero mismatches. Across the 28 selected important bits, 261,846 recovered environment occurrences also produced zero fingerprint-count/environment-count mismatches.

## Randomness

Random state 42 is used for the principal scikit-learn split and modelling workflow. Notebook 05 additionally evaluates neural learning across multiple fixed seeds to separate transfer effects from initialization noise.

## Dependencies

Install the packages listed in `requirements.txt`. Exact cloud-runtime patch versions may evolve; therefore, the executed notebooks and their stored outputs are the authoritative record for the v1.0 analysis. Future releases should add a fully locked environment if exact long-term binary reproduction becomes necessary.

## What is versioned

Versioned in GitHub:

- all six executed notebooks;
- release-facing result tables;
- compact summary figures;
- repository documentation and citation metadata.

Not versioned:

- raw competition data;
- `.npy` / `.npz` feature arrays;
- PyTorch weights;
- fitted `.joblib` objects;
- notebook-output ZIP archives;
- temporary runtime artifacts.

The excluded artifacts can be regenerated by running the notebooks sequentially.
