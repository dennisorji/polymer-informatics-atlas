# Result figures

This directory contains lightweight, release-facing summary figures distilled from the executed six-notebook workflow. The complete high-density Polymer Atlas, property landscapes, holdout-error maps, chemical-support maps, uncertainty maps, Morgan-environment drawings, and structure grids are preserved in the executed notebooks, especially Notebook 06.

Standalone summary figures here are intended for fast review of the principal numerical conclusions. They do not replace the full notebook diagnostics.
